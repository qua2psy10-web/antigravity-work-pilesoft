# 道路橋示方書参照 杭基礎設計システム (Pile Foundation Design System)

本システムは、「道路橋示方書・同解説 IV 下部構造編（平成24年3月 日本道路協会）」「同 V 耐震設計編」および「杭基礎設計便覧」を参照した、杭基礎の概略安定計算・支持力算定・変位法解析・断面応力度照査・杭頭結合部処理・図面プレビュー・計算書出力を行うWebアプリケーションです。正式な設計・施工判断には、適用基準の詳細照査と有資格者による確認が必要です。

---

## 🌟 主な機能

### 1. 地盤条件・液状化検討 (FL法)
- 多層地盤（層厚、土質分類、N値、単位体積重量、粒度特性 $F_c, D_{50}$ 等）の入力
- 設計水平震度（常時、地震時レベル1、レベル2 Type I/II）
- 液状化判定（動的せん断強度比 $R$、液状化抵抗率 $F_L$、地盤反力低減係数 $D_E$ 算定）
- **地盤柱状図・N値プロファイルのリアルタイムCAD描画**

### 2. 杭支持力・地盤バネ算定
- **杭種**: 場所打ちRC杭、鋼管杭 (SKK)、PHC杭、SC杭、鋼管ソイルセメント杭、回転杭工法
- **施工法**: 場所打ち杭工法、打込み杭工法 (打撃/油圧ハンマ)、プレボーリング杭工法、中掘り杭工法、回転圧入工法
- 先端極限支持力度 $q_d$、周面摩擦力 $Q_s$、極限支持力 $R_u$、許容押込み力 $R_a$、許容引抜き力 $R_{pa}$
- 軸方向地盤反力係数 $K_v$、横方向地盤反力係数 $k_H$、杭特性値 $\beta$

### 3. 変位法による杭基礎全体の安定計算 (剛体フーチングモデル)
- 底版寸法（$L_x, L_y, D_f$）、杭配置グリッド（列数、行数、杭間隔、斜杭傾斜角 $\theta$、中抜き設定）
- 杭頭バネマトリックス（$K_1 \sim K_4$）および $3 \times 3$ 連立方程式の求解
- フーチング変位（$\delta_x, \delta_y, \alpha$）、各杭の杭頭反力（$P, H, M, \delta$）
- **Changの弾性梁理論による深度別断面力ダイアグラム（曲げモーメント $M$、せん断力 $S$、変位 $y$、地盤反力 $p$）**
- **杭配置平面図 & 立面断面図のリアルタイムCAD描画**

### 4. 杭体断面応力度照査 & 杭頭結合部設計
- 各荷重ケース（常時、風時、温度時、地震時L1、地震時L2）での応力度照査
- **場所打ちRC杭**: コンクリート曲げ圧縮応力度 $\sigma_c \le \sigma_{ca}$、主鉄筋引張応力度 $\sigma_s \le \sigma_{sa}$、せん断応力度 $\tau \le \tau_a$
- **鋼管杭**: 鋼材合成応力度 $\sigma \le \sigma_a$、せん断応力度 $\tau \le \tau_a$（腐食代考慮）
- **杭頭処理**: 押抜きせん断応力度 $\tau_p$、コンクリート支圧応力度 $\sigma_b$、仮想RC断面照査

### 5. 杭形式比較表 & 道路橋示方書様式 構造計算書
- 各杭種（場所打ち杭 vs 鋼管杭 vs PHC杭）の支持力・概算工事費・施工性・耐震性の多面比較表
- 設計条件、安定計算、断面計算、結果一覧、予備計算、杭頭結合、レベル2地震時、底版照査、基礎バネをまとめた**9章構成の詳細計算書**
- 計算書の章ナビゲーション、荷重ケース別判定、A4印刷・PDF出力、設計データJSON出力
- 鉛直の場所打ちRC杭は20梁要素に分割し、各荷重増分で区間M-φ割線EI、杭軸力、地層別地盤ばねと反力上限pHUを更新して剛体底版の釣合いを反復計算
- L2荷重変位曲線、深度別の曲げ・曲率・地盤反力比・杭体状態、支配杭の初降伏荷重倍率と終局荷重倍率を算定
- 鋼管杭・PHC杭・SC杭・斜杭は、杭ごとの死荷重時軸力と応答点割線EIを用いた杭単体Chang解へフォールバック
- 柱前面曲げ、一方向せん断、柱周囲押抜きせん断による矩形等厚底版の簡易詳細照査
- pHUは土質強度から求める簡易p-y上限であり、正式設計では適用基準の式・上限値との照合が必要であることを画面と帳票に明示
- PHC・SC・鋼管杭の増分解析、テーパー・柱間底版は今後の対象
- 設計プロジェクトのJSONデータ保存および再読込

## 🛠 技術スタック

- **フロントエンド**: React 19 + TypeScript + Vite
- **スタイリング**: Tailwind CSS
- **アイコン**: Lucide React
- **グラフィックス**: HTML5 Canvas API (地盤柱状図、杭配置平面・立面CAD、M/S断面力ダイアグラム)

## 🚀 開発・起動手順

```bash
# 依存パッケージのインストール
npm install

npm run build
```
